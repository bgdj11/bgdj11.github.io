# Project media sources

These files are derivatives of material from Bogdan's public repositories, retrieved 18 October 2026, and local computer animation course materials.

- `animation-lab/`: 19 recordings from the user-supplied INF585-CSC51085EP course folder, resized to at most 760px and converted to looping WebP. Static posters are used on the overview. Exact relative source paths are recorded in `animation-lab/SOURCES.txt`.
- `visual-reasoning/*-en.svg`: English annotation layers over the original saved detection and scene-graph figures; object positions, IDs, confidence values and model outputs are unchanged. The architecture insets use the translated figures too. Reproduce with `node scripts/translate-research-figures.mjs`.

- `visual-reasoning/`: figures from [neurosymbolic-vqa/docs/assets](https://github.com/bgdj11/neurosymbolic-vqa/tree/main/docs/assets), thesis PDF and presentations from `docs/presentation`, English summary from `docs/one-page-summary.pdf`. WebP images preserve the original figures. Both original PPTX files were exported through installed Microsoft PowerPoint to `presentation-en.pdf` and `presentation-sr.pdf` (18 slides each). PDF.js rendered all pages for inspection and produced the current `presentation-*-slide-1.webp` previews. The English default uses the actual English export. Earlier embedded thumbnails and the earlier reconstructed title preview remain unused references; they are not used as slide content. Original research PDFs and PPTX files are unchanged.
- CLEVR imagery: Justin Johnson, Bharath Hariharan, Laurens van der Maaten, Li Fei-Fei, C. Lawrence Zitnick and Ross Girshick, *CLEVR: A Diagnostic Dataset for Compositional Language and Elementary Visual Reasoning*, CVPR 2017. [Dataset and CC BY 4.0 notice](https://cs.stanford.edu/people/jcjohns/clevr/). Figure translations were already present in the source repository.
- `federated-actor-learning/`: PNG outputs embedded in [visualize_domain_shift.ipynb](https://github.com/bgdj11/federated-actor-learning/blob/main/notebooks/visualize_domain_shift.ipynb), cells 4, 7, 10, 12. Exported to WebP; plots were not regenerated with invented data.
- `botanica/`: six images from [SavedPlants](https://github.com/bgdj11/botanica-algorithmica/tree/main/SavedPlants), and three original README recordings hosted under the repository's GitHub assets. Transparent plant drawings are displayed against a CSS matte; image colors are not changed.
- `classical-vision/`: saved image outputs from the three [computer vision notebooks](https://github.com/bgdj11/soft-computing-vision-projects). Image stages, contours and comparison charts are original executed notebook outputs. Game frames are from the project's supplied Buzzy Beetle footage, not original game artwork by the portfolio owner.
- `space-shooter/`: both original [repository gameplay GIFs](https://github.com/bgdj11/space-shooter) remain byte-for-byte as `gameplay.gif` and `combat.gif`. Runtime uses animated WebP derivatives at 900px width, quality 72 (about 2.5 MB and 2.1 MB), retaining the full frame and animation. Poster stills use frames 65 and 35. These recordings demonstrate the project, not ownership of every sprite used inside it.
- `sentiment-chatbot/conversation*`: original `image.png` from [rasa-sentiment-chatbot](https://github.com/bgdj11/rasa-sentiment-chatbot). Stored sentiment metrics come from `src/emotions.ipynb` and are separately represented as selectable HTML.
- `checkmate/logo*`: `frontend/app/src/assets/logoP.png` from [YandexAI-hackathon](https://github.com/bgdj11/YandexAI-hackathon). The repository identifies this as a team hackathon project.
- `diagrams/`: code-native explanatory SVGs from inspected implementation. Current versions are generated by `scripts/generate-case-study-diagrams.mjs`; the earlier `generate-project-diagrams.mjs` and its outputs remain references. These are architecture illustrations, not measured training curves, production traffic or product screenshots. The moderation timeline explicitly uses illustrative event timestamps. Labels are in English.

`media-manifest.json` records source paths/dimensions for the original static image collection. Overview cards use still images; detail animations load lazily and loop natively without playback controls. The VQA figures use English annotation layers; other original notebook rasters retain their labels with English captions where needed. No numbers, experiment outputs or source research files were regenerated or altered.
