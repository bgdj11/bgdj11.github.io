# Social icons

Original PNG assets supplied by Bogdan in `tiny-pixel-social-buttons-v1.3`.
The normal, hover and pressed images are the exported frames of the supplied
`social-buttons-states.png` sheet. Only used platforms are copied here, at native
16 × 16 resolution; CSS scales them by integer factors with nearest-neighbor rendering.

The shared SocialLink component displays the hover frame for pointer hover and
keyboard focus, and the pressed frame during activation. Reduced-motion users
get state changes without positional animation. No continuous animation runs.
